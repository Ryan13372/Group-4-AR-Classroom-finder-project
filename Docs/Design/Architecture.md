# Architecture & Components 

## Context 

This section describes the main components of the AR Classroom Finder and how they work together. 

## Content 

### User Interface: Allows students to search for classrooms and view directions. 

* **Map System:** Displays classroom locations and routes. 

* **AR System:** Shows directions through the user's camera view. 

* **Classroom Database:** Stores classroom numbers and locations.
